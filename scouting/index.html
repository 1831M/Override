Sources & methodology

Where the numbers come from, how they are calculated and what they do not say.

PRIMARY SOURCE

VEX Events API v2

The official VEX Events service supplies event metadata, registered teams, match records, division rankings, skills runs and awards. The page refreshes this feed automatically while open.

VEX Events API documentation ↗Official event page ↗
CLIENT PACKAGE

@v5x/events

A community-developed TypeScript client for the VEX Events API. It handles typed requests, pagination and API retry behaviour. It is not an official VEX product; the underlying results remain sourced from VEX Events.

Package on npm ↗Package documentation ↗
METRIC RULES

How team stats work

  • Win rateWins divided by scored matches in the event response. Unscored matches are excluded.
  • Alliance pointsAverage points for and against from matches containing that team. Shared alliance result, not individual robot contribution.
  • Skills totalBest driver score plus best programming score for the event, not the sum of every attempt.
  • Event rankingVEX's published division ranking, not a custom score invented by this dashboard.
  • Season appearancesRetrieved from the official team event history for the current event season. Failed lookups are marked as unchecked.
DATA QUALITY

What the dashboard will not do

  • No zero-fillMissing or unreturned values stay blank. They are not treated as zero.
  • No robot attributionAlliance scores do not prove what one robot scored or how it performed individually.
  • No stale-as-liveCached snapshots are labelled with their original update time when VEX is unavailable.
  • Season boundarySeason history is filtered to the season attached to this event. Older seasons are not mixed into current performance stats.
  • Video & notebookThe VEX Events API does not provide robot footage or engineering notebook content. These are not rated until separate evidence is linked and reviewed.
ARCHIVE — LEGACY SCOUTING NOTES

Older third-party summaries are kept as research references only. They are not merged into official live rankings or used as current performance facts.
