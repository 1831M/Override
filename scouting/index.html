How to read this dashboard

  • Observed factsDirectly supported by official event records, match results, skills records, notebooks or footage.
  • AnalysisInterpretation derived from observed evidence. It will be labelled as analysis, not fact.
  • UnknownNot yet verified. Unknown values are never silently converted to zero.
  • Reliability scoreProvisional evidence-coverage score, not a ranking of robot ability. Formula: 1 roster point + 1.5 per results event (maximum 3) + 1 for a published skills record + 2 for reviewed footage + 2 for notebook review + 1 for independent source confirmation. Unreviewed categories earn no points.
